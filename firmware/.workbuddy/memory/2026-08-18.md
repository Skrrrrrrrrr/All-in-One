# 2026-08-18 工作日志

## 新增：TCP/UDP Echo 调试样例（设备=Server，PC=Client/NetAssist）

- 需求（用户最终澄清）：PC 端发送"指令"到设备端，设备端把这条指令原样回传。
  设备角色是 **Server（监听端口）**，PC 用 NetAssist 作为 **Client** 发起连接/发送。
  ⚠️ 注意：最初误做成了"设备=Client 连 PC Server"的版本（echo_client.c），被用户
  纠正后已整体删除，重做为 server 版（echo_srv.c）。
- 新增自包含模块 `Drivers/BSP/Src/echo_srv.c` + `Drivers/BSP/Inc/echo_srv.h`
  - 提供 4 个 FreeRTOS+CLI 命令：`echo_tcp_srv [port]` / `echo_udp_srv [port]`
    / `echo_stop` / `echo_status`（默认端口 TCP 8000 / UDP 8001）。
  - 独立 FreeRTOS 任务跑 netconn（顺序 API），不阻塞 CLI；TCP 用
    bind→listen→accept→recv→原样 send 回同一连接；UDP 用 bind→recv→
    netbuf_fromaddr/fromport 取源 → sendto 回传给发送方。
  - 每条收到的数据通过 `vUartRbPrintf()` 以可打印形式打印（`[ECHO_RX]`），便于调试。
- 接入点：
  - `Core/Src/freertos.c` 的 `StartMyTask` 中 `#include "echo_srv.h"` 并调用
    `vRegisterEchoSrvCommands()`（与 `vRegisterLwipTestCommands()` 同级）。
  - 构建：`Debug/Drivers/BSP/Src/subdir.mk` 的 C_SRCS / OBJS / C_DEPS / clean 目标
    各加一行 `echo_srv.*`；编译命令由该文件末尾 `%.o: %.c` 模式规则自动覆盖。
- 编译校验：`arm-none-eabi-gcc`（PATH 内，`/d/VisualCodePlug/arm-none-eabi/bin`）
  单独编译 echo_srv.c 零错误零警告。**注意此工具链不支持 `-fcyclomatic-complexity`**
  （CubeMX 生成 makefile 里带，本地手动编译需去掉）。

## 注意
- `subdir.mk` 是 CubeMX 自动生成的，若用 CubeMX 重新生成代码会覆盖手动新增的
  `echo_srv` 行，需重新添加。
